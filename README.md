# Анализ наличия шлагбаума на парковке

Задача работы — сделать программу, которая определяет наличие шлагбаума на фотографии парковки и выделяет найденный объект рамкой.

## Что было сделано

- проверил стандартную модель YOLOv8 и выяснил, что отдельного класса шлагбаума в ней нет;
- нашёл датасет с классом `gate barrier` и подготовил изображения для обучения;
- разделил данные на обучающую, проверочную и тестовую выборки;
- обучил модель YOLOv8n;
- подобрал порог уверенности для детекции;
- проверил модель на тестовых и новых изображениях;
- сделал простой веб-интерфейс для загрузки фотографий;
- добавил сохранение результатов и истории проверок в JSON и Excel.

## Полученный результат

На тестовой выборке модель получила `mAP50 = 0.7392`. После проверки на валидационной выборке был выбран порог уверенности `0.021`. При этом значении accuracy составила `0.9286`, а F1-мера — `0.9032`.

Модель выводит информацию о наличии шлагбаума, показывает количество найденных объектов и сохраняет изображение с рамкой.

## Содержимое репозитория

- `Арзамазов_Д_В_УБВТ_2401.ipynb` — основной ноутбук со всеми этапами работы;
- `dataset_yolo` — подготовленный датасет в формате YOLO;
- `runs` — результаты обучения, графики, метрики и веса модели;
- `report_materials` — материалы, использованные при подготовке отчёта;
- `user_images` и `user_results` — загруженные изображения и результаты их обработки;
- `web_uploads` и `web_results` — файлы веб-интерфейса;
- `detection_history.json` — история проверок;
- `history_barrier_detection.xlsx` — история проверок в формате Excel;
- `project_info.json` — основная информация о модели и путях к файлам.

Лучшие веса обученной модели находятся по пути:

```text
runs/barrier_yolov8n_1789593023/weights/best.pt
```

## Как запустить ноутбук

1. Открыть файл `Арзамазов_Д_В_УБВТ_2401.ipynb` в Google Colab.
2. Последовательно запустить ячейки сверху вниз.
3. Дождаться установки библиотек, подготовки датасета и обучения модели.
4. В конце ноутбука открыть ссылку на веб-интерфейс и загрузить фотографию для проверки.
